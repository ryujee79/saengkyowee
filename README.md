# 학생생활교육 징계 산정

나이스 출결 자료와 생활지도 목록을 브라우저에서 분석해 학생별 징계 기준을 계산하는 웹앱입니다.

## 주요 기능

- 나이스 출결 XLS/XLSX 파일 여러 개 업로드
- 생활지도 목록 XLS/XLSX 파일 업로드
- 기본생활 벌점과 근태 기준을 합산해 징계 산정
- 1·2·3학년 생활지도 탭 자동 분류
- 항목별 `미이수` 체크 및 다음 징계 단계 승급
- 통합 결과 검색·필터링
- 산정 결과 XLSX 다운로드

업로드한 파일은 사용자의 브라우저 안에서 처리합니다. 별도의 서버 저장 기능은 구현되어 있지 않습니다.

## 실행 방법

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

검증 및 배포용 빌드는 다음 명령으로 실행합니다.

```bash
npm test
npm run build
```

## 계산 기준

세부 기준은 웹앱의 `기준표` 탭과 `lib/discipline.ts`에서 확인할 수 있습니다.
